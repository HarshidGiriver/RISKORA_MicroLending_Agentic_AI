# RISKORA V1.0 Development Baseline

## Current release
RISKORA V1.0 is a transparent, deterministic prototype. It does not claim to use artificial intelligence.

### Modules in this baseline
- Loan request board and borrower profiles
- Rule-based risk scoring and explanation
- Manual assessment using the same engine
- Historical CSV dataset validation
- Search, filter, sort and record-level reports
- Single-Lender Funding
- Fractional Funding
- Repayment schedule configuration
- Pro-Rata Allocation (default), Largest Contribution First, Earliest Funding First
- Lender exposure view
- Module risk register and controlled test-case library

## Future releases
### V2.0 — AI/ML risk prediction
Use historical loan outcomes to train and evaluate a model. Compare model performance against the V1.0 deterministic baseline before making AI the primary risk engine.

### V2.5 — Explainable AI
Show model probability, contributing features and confidence/limitations.

### V3.0 — Automation and feedback
Automated API/UI tests, defect feedback, dynamic prioritization and continuous regression support.

## Design principle
The interface should remain professional and restrained. AI should be part of the processing layer when it is genuinely implemented, not represented by chatbots, robot graphics or decorative AI visuals.
